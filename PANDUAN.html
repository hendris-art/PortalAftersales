Aplikasi ORIENT Aftersales

Cara memasang aplikasi di HP Android, iPhone, dan komputer Windows/Mac

1Isi URL portal (sekali saja)

  1. Di Apps Script buka Deploy → Manage deployments, salin Web app URL (berakhiran /exec).
  2. Buka file index.html di folder ini, cari baris const APP_URL = ''; lalu tempel URL di antara tanda kutip. Simpan.
Boleh dilewati: bila APP_URL dikosongkan, aplikasi akan meminta URL saat pertama dibuka dan menyimpannya di perangkat.

2Unggah ke GitHub Pages (gratis, 5 menit)

  1. Masuk ke github.com (buat akun bila belum ada) → New repository → beri nama orient-app → Public → Create.
  2. Klik uploading an existing file, lalu seret seluruh isi folder orient-app (termasuk folder icons) → Commit changes.
  3. Buka Settings → Pages → Source: Deploy from a branch, Branch: main / (root) → Save.
  4. Tunggu ±1 menit. Alamat aplikasi: https://NAMA-AKUN.github.io/orient-app/
Bagikan alamat itu ke tim. Setiap kali portal (Apps Script) diperbarui, aplikasi otomatis ikut terbaru — tidak perlu memasang ulang.

3Pasang di perangkat

HP Android (Chrome)Buka alamat aplikasi → menu ⋮ → Instal aplikasi / Tambahkan ke layar utama. Ikon ORIENT muncul di layar utama dan daftar aplikasi.
iPhone / iPad (Safari)Buka alamat aplikasi → tombol Bagikan □↑ → Tambah ke Layar Utama → Tambah.
Windows / Mac (Chrome atau Edge)Buka alamat aplikasi → klik ikon Instal ⊕ di ujung kanan bilah alamat (atau menu ⋮ → Instal ORIENT Aftersales). Aplikasi muncul di Start menu / Launchpad dan bisa di-pin ke taskbar.
Di dalam aplikasi ada tombol logo ORIENT kecil di pojok kanan bawah (bisa digeser): Muat ulang, Buka langsung, Pasang aplikasi, Layar penuh, dan Ganti URL.

4Ingin file installer (.apk / Windows)?

  1. Setelah langkah 2 selesai, buka pwabuilder.com, tempel alamat aplikasi (https://NAMA-AKUN.github.io/orient-app/) → Start.
  2. Pilih Package for stores → Android (menghasilkan file .apk untuk dipasang langsung dan .aab untuk Play Store) atau Windows (paket .msix).
  3. Unduh, lalu bagikan file .apk ke HP tim (izinkan "Instal dari sumber tidak dikenal" saat diminta).

5Bila portal tidak tampil di dalam aplikasi

  • Pastikan sudah masuk (login) ke akun Google @orient.co.id di browser yang sama.
  • Gunakan menu Buka langsung: portal dibuka penuh tanpa bingkai aplikasi (cocok bila browser memblokir cookie pihak ketiga).
  • Pastikan versi Code.gs terbaru sudah di-deploy (pengaturan XFrameOptionsMode.ALLOWALL sudah ada di dalamnya).
  • Opsional: isi APP_ICON_URL di Code.gs dengan https://NAMA-AKUN.github.io/orient-app/icons/icon-192.png agar ikon ORIENT juga tampil di tab browser portal.
